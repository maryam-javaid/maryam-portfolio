Brand Reputation Monitoring & Sentiment Alert System

An n8n workflow that runs on a schedule, pulls fresh mentions from a news API, and passes them through an AI agent (Gemini) to classify sentiment. Results are logged to a sheet, and negative or positive posts automatically trigger a Slack alert — so reputation issues get flagged the moment they happen instead of during a manual check.

A lightweight Python desktop app that scans a selected folder and automatically sorts its contents into categorized subfolders by file type. Built with a simple, no-clutter GUI so anyone can clean up a messy downloads folder in a couple of clicks instead of dragging files around by hand.
